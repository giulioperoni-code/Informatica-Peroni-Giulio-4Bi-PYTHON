# Scheda personale di postazione

## Hardware

Il computer usato in laboratorio è un PC Windows 11 dotato di un processore Intel Core i7 con 16 GB di RAM. La configurazione è adatta a svolgere esercitazioni di programmazione, gestione di repository e scrittura di documentazione tecnica senza rallentamenti evidenti.

La scheda madre e il case sono quelli standard della postazione didattica, mentre l'unità di archiviazione è un SSD da 512 GB. Le prestazioni sono sufficienti per avviare Visual Studio Code, compilare progetti Java e usare Git in modo regolare.

### Componenti principali

Il sistema dispone di un monitor 24 pollici, tastiera e mouse USB, oltre a una connessione di rete stabilizzata. L'hardware è stato verificato con il sistema operativo e con le applicazioni del corso, senza che si rilevino problemi di compatibilità.

Le prestazioni complessive sono buone per lavorare in modo produttivo e per eseguire più finestre contemporaneamente, come il browser, il terminale e l'editor di codice.

## Software installato

Sul computer sono installati Visual Studio Code, Git, Java Development Kit e il supporto necessario per lo sviluppo in ambiente didattico. L'ambiente di programmazione è stato aggiornato per garantire compatibilità con i file di progetto e le esercitazioni del corso.

La versione di Visual Studio Code in uso è la 1.9x, mentre il JDK disponibile è Java 17. Git è installato nella versione 2.4x. Questi strumenti permettono di aprire il repository, compilare sorgenti Java e controllare lo stato del lavoro in modo semplice.

### Strumenti principali

Il terminale è usato per eseguire comandi come `git status`, `git clone` e `javac`, mentre l'editor permette di scrivere documenti in Markdown e gestire più file in modo ordinato. L'uso del terminale è essenziale per verificare i passaggi della consegna e per mantenere i file organizzati.

L’ambiente di lavoro è inoltre pronto per il supporto a Python e per l'uso di notebook locali, senza dipendere da servizi remoti.

## Credenziali e servizi del corso

Per gli accessi ai servizi del corso si usa il proprio account personale e le credenziali assegnate dall'istituto. Le informazioni di accesso non vengono riportate nel documento: in particolare non compaiono password né token di autenticazione.

Il repository del corso viene usato per caricare le consegne e tenere traccia dei file prodotti durante il laboratorio. Inoltre, il Jupyter locale permette di creare e verificare i notebook senza usare il server remoto del laboratorio.

### Servizi utilizzati

Tra i servizi principali ci sono il repository GitHub personale, il sistema di file locale e l'ambiente di sviluppo installato sul PC. Con questi strumenti il lavoro può essere svolto in modo ordinato e verificabile durante le lezioni.

Il percorso principale di lavoro è il repository del corso, mentre i notebook sono salvati in una cartella dedicata del progetto e controllati con l'esecuzione del kernel locale.
