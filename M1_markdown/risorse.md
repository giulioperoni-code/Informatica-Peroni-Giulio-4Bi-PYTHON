# Risorse del corso

## Collegamenti utili

- [Markdown Guide](https://www.markdownguide.org/) è una risorsa chiara per imparare la sintassi base e le regole di formattazione.
- [CommonMark](https://spec.commonmark.org/) è la specifica ufficiale del formato Markdown, utile per verificare la compatibilità dei costrutti.
- [Documentazione di Pandoc](https://pandoc.org/) spiega come trasformare documenti Markdown in altri formati come HTML e PDF.
