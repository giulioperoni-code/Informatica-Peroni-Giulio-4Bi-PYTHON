# README del progetto

## Benvenuti

Questo programma permette di analizzare i dati di un file CSV e mostrane un riepilogo in console.

### Come usare

Apri il programma con Java e passagli il file csv. `javac` dovrebbe essere installato. Il progetto usa la classe `Main` e legge il file `dati.csv`.

## Requisiti

- Java 8
- Un file CSV
- una cartella di lavoro

### Passi

1. Scarica il repository
2. Vai dentro la cartella
3. Compila il codice usando `javac` 
4. Esegui il programma con `java Main`

Il programma stampa a video i risultati ma non salva file. E' molto semplice.

## Output

The output is in console and the program finish.

### Avvisi

Questo README e' stato scritto in fretta e potrebbe contenere errori tecnici.

Il nome della classe principale e il nome del file devono essere verificati prima di consegnare il lavoro.
